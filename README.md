# MyProfile — консольное приложение для хранения и вывода профиля

Простое учебное консольное приложение на Python для ввода, валидации и вывода личной и банковской информации пользователя (индивидуального предпринимателя). Позволяет постепенно заполнять данные и выводить их в удобном виде через меню.

## Возможности
- Главное меню с навигацией:
  - 1 — Ввести или обновить информацию
  - 2 — Вывести информацию
  - 0 — Завершить работу
- Подменю ввода/редактирования (пункт 1):
  - Личная информация: имя, возраст, телефон, e‑mail, индекс, адрес, доп. сведения
  - Информация о предпринимателе: ОГРНИП, ИНН, р/с, банк, БИК, к/с
- Подменю вывода (пункт 2):
  - Личная информация
  - Вся информация (личная + банковские реквизиты)
- Валидация ключевых полей (возраст, телефон, индекс, длина числовых реквизитов)
- Грамматически корректный вывод возраста («год/года/лет»)

## Структура проекта
- main.py — точка входа и логика главного меню
- input_helpers.py — вспомогательные подменю для ввода и вывода данных
- user_info.py — ввод и печать личной информации, склонение «лет»
- bank_info.py — ввод и печать банковской информации ИП
- validation.py — функции валидации: возраст, индекс, телефон, длина чисел
- README.md — этот файл

## Логика работы меню (схема)
Главное меню:
- 1 — Ввести или обновить информацию → Подменю ввода
  - 1 — Личная информация → последовательно запросит:
    - Имя (строка)
    - Возраст (целое число > 0)
    - Телефон (+7XXXXXXXXXX). Разрешается ввод с произвольными символами: будут отфильтрованы только цифры, проверяется 11 цифр и что номер начинается с 7
    - E‑mail (строка, без дополнительной валидации)
    - Почтовый индекс (строго 6 цифр)
    - Почтовый адрес (строка)
    - Дополнительная информация (необязательно)
  - 2 — Информация о предпринимателе → запросит:
    - ОГРНИП (15 цифр)
    - ИНН (целое число; в текущей версии без проверки длины)
    - Расчетный счет (20 цифр)
    - Название банка (строка)
    - БИК (целое число; в текущей версии без проверки длины)
    - Корреспондентский счет (целое число; в текущей версии без проверки длины)
  - 0 — Назад → возврат в главное меню (с сохранением введенных значений в памяти до завершения работы)
- 2 — Вывести информацию → Подменю вывода
  - 1 — Личная информация (краткий профиль)
  - 2 — Вся информация (личная + банковская)
  - 0 — Назад
- 0 — Завершить работу

Примечание: данные хранятся только в оперативной памяти в рамках одного запуска. Сохранение в файл/БД не реализовано.

## Валидация
Реализована в файле validation.py:
- count_symbols(text) — извлекает цифры из текста и возвращает (кол-во_цифр, строка_из_цифр)
- postcode_check(prompt) — запрашивает индекс до тех пор, пока не будет ровно 6 цифр
- phone_check(prompt) — принимает ввод, фильтрует до цифр и проверяет 11 цифр, первая — 7; возвращает в формате +7XXXXXXXXXX
- age_check(prompt) — запрашивает возраст до тех пор, пока не будет целым числом > 0
- count_ciphers(number) — считает количество цифр в числе
- ciphers_quantity_check(prompt, name, n) — проверяет, что введенное число содержит ровно n цифр
